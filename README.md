# Courtly Landing Page

Courtly is a digital platform focused on simplifying sports organization by allowing users to reserve sports courts, connect with independent coaches, and manage matches from a single platform.

This repository contains the official landing page for the Courtly project, developed as part of an academic software engineering and web development initiative.

## Overview

The landing page was designed to present the core features and value proposition of Courtly through a modern, responsive, and user-friendly interface.

The project focuses on:

- Sports court reservations
- Independent coach discovery
- Match organization
- Subscription plans
- Responsive user experience
- Multi-language support

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages
